# DRAW RACE

Draw your horse. Race your friends. Bad art, great races.

Рабочая бесплатная браузерная party game: редактор рисунков, процедурная анимация точного пользовательского изображения, комнаты на 2/4 человека, гонка 90 секунд, пять S-поворотов, восемь препятствий, погода, результаты, реванш и детерминированный повтор.

## Быстрый локальный запуск

Нужен Node.js 22.18+ и npm. В папке проекта:

```sh
npm ci
npm run local
```

Открыть **http://localhost:5174/**. Node backend — порт 8788. Для друзей в одной Wi-Fi сети открыть адрес LAN, напечатанный Vite. Для полноценного доступа с телефона из другой сети нужен публичный HTTPS-хостинг и работающий сервер. `localhost` на чужом телефоне не ведёт на ваш компьютер.

В этой Windows-сессии системная npm-обёртка неправильно определяла путь. Рабочий обход:

```powershell
$env:npm_config_cache = "$env:TEMP\draw-race-npm"
node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' ci
node scripts/local.mjs
```

## Самостоятельное размещение на обычном Node-хостинге

```sh
npm ci
npm run build:standalone
npm run serve:standalone
```

Node отдаёт собранный frontend и API по одному адресу, порт `PORT` (по умолчанию 8788), интерфейс `HOST` (по умолчанию 0.0.0.0). Подключить reverse proxy с HTTPS и WebSocket upgrade `/ws`. В dev-режиме Vite проксирует `/api` и `/ws` на Node. Данные комнат — в `room-data`, путь можно задать через `ROOM_DATA`. Хранить эту папку на постоянном диске. FileStore рассчитан на **один Node-процесс**, не на несколько реплик. Секреты сессий не входят в исходники или сборку.

Для Sites используется отдельный Worker build: `npm run build`. Сохранены интеграция Sites и `.openai/hosting.json`. Backend использует D1 и optimistic compare-and-swap по revision. SQL/Drizzle-миграция включена. У размещённой версии синхронизация HTTP раз в 1.5 секунды и единая временная шкала сервера; каждый кадр проигрывается локально. У Node-версии дополнительно есть WebSocket-уведомления с тем же HTTP fallback. Polling выбран для совместимости с доступными Sites bindings; отдельного постоянно работающего Node-сервера Sites не предоставляет.

## Что работает

- Quick Race: ваш рисунок против **трёх явно обозначенных ботов**. Публичного матчмейкинга нет.
- Challenge Friend: два реальных игрока; 4 Player Race: четыре реальных игрока. Код комнаты и ссылка, вход без регистрации, автоматический старт после READY у всех.
- Canvas: мышь/палец/стилус, восемь цветов, толщина кисти, ластик, undo/redo, очистка, сохранение прозрачного PNG. Рисунок остаётся пользовательским; модели лошадей не подставляются.
- PixiJS MeshPlane 13×9: деформация ног/корпуса, подпрыгивание, squash/stretch, наклоны, клевок головой, опрокидывание. Если WebGL недоступен — деформация полосами Canvas.
- Три типа трасс; пять виражей и восемь барьеров/луж/грязевых/ледяных участков. Ясно, дождь, встречный или попутный ветер, мороз. Всё из одного seed.
- Длина — **90 секунд**, плюс стартовый отсчёт. Ускорения, замедления, камбэки, заносы, прыжки. Счёт финиша ведётся по цветному маркеру корпуса, длина носа не даёт раннего финиша.
- Seed фиксирует все результаты, события и погоду. Reload комнаты восстанавливает место по локальному session token. Краткое отключение не отменяет гонку; после возврата клиент догоняет серверное время.
- После гонки — рейтинг, время, PLAY AGAIN, повтор, участок фотофиниша, карточка победителя PNG, Share API / копирование ссылки. Запись 8-секундного клипа там, где поддерживается MediaRecorder.
- Звуки синтезируются Web Audio без платных API и внешних аудиофайлов. Имя, звук, текущий рисунок и последние 12 гонок сохраняются на устройстве.

## Баланс с учётом последних изменений задания

Первоначальное условие 50%/25% независимо от рисунка заменено пожеланием пользователя: **70% случайный балл + 30% геометрия/условия трассы**. Это веса баллов, не гарантия вероятности победы. При одинаковых рисунках шансы симметричны.

Скорость, прыжок и сцепление делят 150 очков; каждый атрибут ограничен диапазоном 25–75. Худой скоростной силуэт теряет устойчивость; тяжёлый устойчивее, но хуже в скорости/прыжке. Разные трассы по-разному взвешивают атрибуты. Геометрическая эвристика по маске рисунка оценивает относительный передний свес и высоту шеи. Это **не распознавание анатомии**; выводимые характеристики — оценка, её можно обмануть нестандартной формой. Художественное качество не оценивается.

Удлинение переднего свеса увеличивает риск headplant. При экстремальном рычаге появляется гарантированное событие `topple`; обычные падения выбираются из seed. Встречный ветер/скользкая трасса усиливают риск. Удар снижает вклад формы в итоговый балл и замедляет движение, а не только показывает анимацию. Штраф остаётся в пределах 30% компонента формы. Это первая балансная настройка: 1000 симметричных прогонов — проверка отсутствия грубого преимущества места, **не доказательство отсутствия оптимального шаблона рисунка**.

## Проверяемость и её пределы

Сервер публикует SHA-256(secret) до рисования. При READY игрок отправляет собственный случайный nonce и рисунок, которые после готовности не меняются. Из secret + code + round + версии + упорядоченных ID/nonce/рисунков получается SHA-256 seed. После фиксации всех участников сервер раскрывает secret и единый timestamp старта. Клиент проверяет хеш и сохранённый commitment, длительность и выбор трассы. Состав/рисунок/seed нельзя незаметно заменить в квитанции.

Это **не VRF**. Бесплатный сервер всё ещё способен прекратить обслуживание/сорвать выдачу результата; подключившийся уже после раскрытия клиент не видел первоначальный commitment. На этом нельзя строить доверенную денежную выплату. См. [docs/SOLANA_DEVNET.md](docs/SOLANA_DEVNET.md) для честного статуса on-chain части.

## Проверки

```sh
npm run typecheck
npm test
# При работающем Node backend:
node scripts/smoke.mjs
# Для другого origin:
# TEST_ORIGIN=https://... node scripts/smoke.mjs
```

11 автоматических тестов: конкурентные joins/READY для 2/4 игроков; приватность secret/session token; блокировка состава; квитанции и подмена рисунков; идентичный повтор и монотонное движение; реванш; права host; таймаут; восстановление места; отклонение некорректных рисунков; постоянство общего бюджета; симметричные шансы; файловая персистентность/CAS; погода/препятствия/повороты; последствия длинной морды. HTTP/WebSocket smoke запускает независимых игроков с разными session tokens и сверяет общий seed и startAt.

В браузере проверены рисование, READY, анимация точного рисунка, результаты, PLAY AGAIN, телефонная ширина 390px без горизонтального скролла. Это не реальный тест Safari/iPhone или Android Chrome; такие устройства в этой среде недоступны. Тестирование опубликованного D1 backend выполняется отдельно от Node. Локальный Wrangler preview в данной Windows-песочнице блокировался чтением корня диска при резолвинге esbuild; Worker build при этом проходит.

## Ограничения

- Solana-кошелёк/escrow/VRF/выплаты **не реализованы и не развёрнуты**. Отключено, фиктивных транзакций нет.
- Угроза распознавания формы и оптимальных шаблонов требует живых плейтестов и более качественного определения частей тела.
- Звук зависит от разрешённого пользователем первого нажатия. Экспорт видео зависит от браузера; PNG доступен как основной формат.
- 10 минут на рисование; комната недоступна через 24 часа. Данные истёкших комнат пока могут физически оставаться в хранилище до очистки оператором.
- Host может освободить место отключённого игрока через 45 секунд до гонки. После финиша host может переоткрыть комнату. Если host ушёл и не возвращается, проще создать новую комнату.
- Одна browser localStorage-сессия = один игрок. Две вкладки одного браузерного профиля восстанавливают того же игрока; для второго тестового игрока нужен другой браузер/профиль/устройство.
- Нет публичного матчмейкинга, чата, серверного видеорендера, защиты масштаба массового коммерческого сервиса или анатомической сегментации.
- Нет платных AI API/подписок. Для запуска из чистого checkout нужен интернет для npm; бесплатные Google Fonts загружаются при доступности, иначе используются системные fallback-шрифты. Серверные квоты и стоимость хостинга зависят от выбранной площадки.

## Основные файлы

- `components/draw-race.tsx` — игровой цикл и UI.
- `components/drawing-editor.tsx` — редактор; `components/race-surface.tsx` — гонка и анимация.
- `lib/game.ts`, `traits.ts`, `course.ts` — версия расчёта, характеристики, погода и события.
- `lib/rooms.ts` — общий авторитетный API; `lib/d1-store.ts` — размещённые комнаты.

- `tests/game.test.ts`, `scripts/smoke.mjs` — проверки.
- `scripts/estimate-costs.mjs` — read-only запрос стоимости rent и состояния VRF в Devnet.
