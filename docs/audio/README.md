## What the AI generated

Google Magenta MusicVAE mel_2bar_small generated twelve new symbolic melody candidates, using seeded latent vectors. This is actual neural inference, not a claim that procedural accompaniment was generated by Suno. Raw outputs, latent vectors, seeds, versions and checkpoint hashes are retained in musicvae-motifs.json and generation-provenance.json.

MusicVAE is not a natural-language model. The genre/tempo/instrument/structure briefs in production-briefs.json guide the authored arrangement. The selected neural contours were octave-folded, fitted to a major scale and current chord, and varied across phrases. Harmony, bass, rhythm, countermelodies and the finishing cadence are original authored arrangement.

All audio uses original additive oscillators and deterministic filtered-noise percussion. There are no imported soundfont, sample-pack or song recordings, no vocals and no artist imitation.

## Playback and looping

The site plays static 80 kbps mono MP3s at a 32 kHz sample rate. No AI model runs during gameplay. Loop masters are synthesized at exact integer sample counts, with notes/reflection tails wrapped periodically. A circular shift chooses a quiet zero crossing near the musical boundary; no fade is applied to loop masters. The one-shot result cue has a natural tail.

Use manifest.loopStart / manifest.loopEnd after gapless decoding, rather than the MP3 container duration. ffprobe includes MP3 frame padding; ffmpeg decoding restores the exact master sample count for all four files. Parent audio-system integration handles scene transitions, ducking, user volume and browser autoplay.

mastering-report.json records objective loudness/true-peak, RMS, sample counts, loop-boundary jumps and file sizes. No subjective listening review is claimed in that report.

## Reproduction

Rendering existing retained neural motifs requires Node.js and FFmpeg/ffprobe:

    node scripts/music/synthesize-soundtrack.cjs /absolute/path/to/temporary-masters

FFMPEG_PATH and FFPROBE_PATH may select executables explicitly. The script also recognizes isolated Windows binary packages under ../work/music-tools/node_modules, since this host's WinGet PATH symlinks were inaccessible. It does not modify application dependencies.

To regenerate neural motifs, use scripts/music/generate-motifs.cjs with an isolated MUSIC_TOOLS_DIR. Copy generation-package.json and generation-package-lock.json from scripts/music into that directory as package.json and package-lock.json, then run npm ci --ignore-scripts there. The official checkpoint is downloaded and hashed there, outside the app source; generated raw candidates stay there until explicitly selected for the score.
